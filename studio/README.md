# `studio` package

PydanticAI agents + Phaser assembler. Run from the **repo root**:

```bash
python -m studio briefs/rabbit_side_scroller.json --name my_game
```

See the root [README.md](../README.md) for setup, `.env` locations, and flags.

`.env` is loaded from the folder above this package and/or `studio/.env` (see `env_loader.py`).
